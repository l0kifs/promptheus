# План исправления проблемы 1.1: Нарушение layered architecture и dependency injection

## Проблема 1.1: Layered Architecture (SAD §1, §2)

### Описание проблемы
- **Документация**: Четкое разделение на слои (Bot Interface → Application Core → AI Integration / Data Access), dependency injection, stateless design
- **Реализация**: Нарушение DI (прямое использование `get_db()` в handlers), создание репозиториев внутри методов, состояние хранится в памяти вместо DB

### Критичность: 🔴 Высокая
- Блокирует масштабируемость и тестируемость
- Нарушает SOLID принципы
- Увеличивает coupling между компонентами

## Риски и mitigation

### Риски
- **Downtime**: Возможны проблемы при развертывании
- **Performance**: Async может добавить overhead
- **Data loss**: Ошибки в миграции состояния сессии

### Mitigation
- **Тестирование**: Полное тестирование перед релизом
- **Gradual rollout**: Feature flags для поэтапного включения
- **Backup**: Полный backup перед миграцией
- **Monitoring**: Детальное логирование и метрики
